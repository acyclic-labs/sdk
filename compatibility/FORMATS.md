# Decoder and format inventory

This inventory joins wire identity, persisted format versions, golden bytes,
fuzz entry points and bounded proofs. The protobuf inventory is generated from
`acyclic_proto_build::FAMILIES`: every message, including nested messages, has
a typed entry in `acyclic-codec-fuzz::DECODERS`. A protobuf package version owns
its RPC route; framing and semantic decoders are separate boundaries below.

Fuzzing and proofs run on demand. A source entry is not evidence of an executed
campaign or proof. Captured corpus provenance is `rust/codec-fuzz/corpus/SOURCES.tsv`;
descriptor baselines live in `compatibility/descriptors/`. Golden payloads belong
in `compatibility/frames/`, alongside their producing encoder and refusal cases.

Version checks must precede payload interpretation and side effects. A refused
version never triggers migration, repair, truncation or rewrite. Tests mutate a
captured version and truncate its body to establish this ordering. Invalid input,
trailing input, EOF and owner loss are distinct negative controls where applicable.

The corpus currently contains 882 real encoder outputs, including all 403
generated message types and their JSON projections. All 882 passed decoder
replay with recorded lengths and SHA-256 values. Their exact bytes also appear
under `corpus/` names in the one shared golden lookup. Encoder comparison
against that newly installed baseline and format-specific refusal execution
remain separate obligations; replay alone does not establish either. These
captures and the successful replay predate the addition of Stream record
origins. Current encoder capture and replay must be repeated after integrating
that schema change; historical results do not qualify the current source.

The Harness descriptor baseline was captured with Buf 1.75.0 from the actual
schemas using `buf build --path rust/crates/harness-core/proto/harness/v2/harness.proto
--path rust/crates/harness-core/proto/protocol/v1/protocol.proto --output
compatibility/descriptors/harness-v2.bin`. The shared descriptor equality check
still needs execution for this added family. The new table appends its 84
messages after the original 403, preserving the captured selectors.

Fixed-width codecs do constant work. Variable payload codecs necessarily take
work proportional to the admitted payload; their cost must not depend on retained
history, object count or unrelated agents. Byte parsers perform no syscalls,
durability barriers, round trips, waits or polling. Session version admission
uses the same first flight as the first interest and adds no negotiation request.

The private `MemoryGenerationPathIndex` uses its APQ v1 codec only for
process-local acceleration. It has no persisted or wire backend and is excluded
from persisted-format version claims. Git's `acyclic-fs-manifest-v2` archive is
an output format with no corresponding SDK input decoder; its writer still
must preserve the complete generation identity (G96).
