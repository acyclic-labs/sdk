Use native `spawn_agent` once. Inside its isolated workspace it must run `acyclic git status`, create `git-local.txt` with exact content `git compatible\n`, run `acyclic git add git-local.txt`, run `acyclic git commit -m "eval local commit"`, run `acyclic git status` again, and separately run bare `git --version` to prove ordinary Git still resolves to system Git. It must not use system Git to operate on the isolated workspace. Publish the child with `agent_merge` and verify the file. Do not create the file yourself.
