# Acyclic SDK transport bindings

Protobuf messages and gRPC stubs generated with maintained tools from canonical
Rust descriptors. `rust-authority.json` records the exact source revision and
input digests. `LICENSE` and `NOTICE` accompany the generated package.

These transport bindings do not implement Rust validation, error policy,
transport selection, cancellation, recovery or an embedded Rust runtime.
Qualification results must identify their actual installed package and scope.
