# Agent boundary proofs

The unbounded limit audit retires the slot arithmetic package, its reservation
mutants and the maximum-record properties. Child membership now persists as
immutable indexed nodes; checkpoints retain roots and counts. The membership
property exercises insertion, duplicate completion, immutable snapshots, reopen
and cursor pagination against an independent set.

The deterministic agent step still rejects empty or control-containing host
names before publishing effects. There is no host-name byte ceiling.

The generated `ExplicitStreamProvider` removes defaults from the canonical
provider declaration. Missing adapter implementations fail compilation,
including future default methods. Its independent property checks every attested
write family, original local/admitted authority, exact canonical digests and
retry evidence. The external attestor retains its documented deterministic
function obligation. These controls remain in `rust/proofs/spawn-slots/run.py`.

`rust/proofs/spawn-slots/proofs.json` retains the historical execution receipts
with their exact source pins. Retired cap receipts do not qualify the new index.
