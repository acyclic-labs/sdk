`native_host_admission` includes the production `host_hooks.rs` and uses the
shared command parser. Its corpus is the original captured host output in
`rust/crates/harness/fixtures/hosts`, with provenance alongside those bytes.
Own hook configuration is generated by the production formatter for every
UTF-8 input path; it is not a substitute native host response.

From the repository root, replay the corpus with:

```sh
cargo run --locked -p acyclic-harness-fuzz --no-default-features --features core --bin native_host_admission -- rust/crates/harness/fixtures/hosts -runs=0 -seed=1
```

For an instrumented campaign use the same target and corpus through cargo-fuzz.
Ordinary corpus replay is not instrumented coverage or installed-host evidence.

Apply each patch separately to the original production source. The unchanged
oracle must reject `reject-supported-version.patch` at its original captured
supported-version assertion, and `claim-foreign-group.patch` at its extra-field
ownership assertion. A compiler or setup failure does not qualify either
defect. Restore the source before the next control. The native shell argument
delivery test remains separate: parser/formatter agreement cannot prove OS
shell behavior.
