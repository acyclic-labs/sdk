# Scaling by graph and agent count

Start with the quantity task as a smoke check. For an inferential pilot prepare
independent task/cut clusters of comparable difficulty before running anything.
Use participant counts 1, 2, 4 and 8 as explicit pilot choices, not product
limits. Reserve 20 assigned trials per arm for a selected comparison; the files
begin with a two-participant chain versus a two-participant fan-out. Obtain
approval before expanding this pilot matrix or increasing counts.

The count includes task-solving participants and the final join participant;
report trial-coordinator and population-source overhead separately. Keep model,
evidence, grant reach and aggregate model-token reservation fixed across matched
conditions. Record actual calls/tokens, rather than assuming every participant
used its allocation. A missing budget-reservation mechanism blocks that contrast.

Bind each graph as data through the shared scope topology mechanism. Chain means
directed predecessor delivery; fan-out means independent first participants and
one final join. At count 1 these coincide and must not be reported as independent
topology evidence. Other graph families, including cyclic rings, need explicitly
selected termination and forked-stream semantics before admission. Do not infer
a graph from a topology word in a brief.

Primary outcomes are correctness per assigned trial and paid USD per assigned
trial. Report cost coverage, failure rate, critical-path duration and total
provider tokens. Use original execution/commit spans for latency attribution;
no periodic resource probes. Report paired deltas per size/graph within problem
and cluster over independent problem cuts. Eight participants and a few points
do not establish an asymptotic scaling law; fit exploratory curves only with
uncertainty and the measured range shown.

Negative controls: verify observed members/edges equal the bound graph and
requested count; count-1 graph conditions must coincide; a missing join producer
ends in typed error. A mismatch is an invalid topology trial, not a low score.

Needed: real graph binding/count verification, user reservation, scope termination,
original spans, lifecycle release and role fence. Not executed.
