# Context composition

The ordered context pipeline validates every stage against admitted limits.
Selections preserve complete tool exchanges; mandatory content cannot be silently
truncated. Immutable renderer contracts and pinned attributes determine input.

`ModelStarted` retains the prepared request. Replay verifies its canonical bytes
and digest before using completion or reconciliation, without rerunning sources.
A replacement pipeline affects future admissions; in-flight operations retain
their original configuration.
