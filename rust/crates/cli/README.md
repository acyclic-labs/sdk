# acyclic-cli

Small local command-line demonstration of the Acyclic Harness runtime. It runs a recursive task-group workload and prints the outcome; it is not a hosted service or administration CLI.

```sh
cargo install acyclic-cli
acyclic-cli
```

For application integration, use [`acyclic-harness`](https://docs.rs/acyclic-harness/latest/acyclic_harness/) or the [`acyclic-sdk`](https://docs.rs/acyclic-sdk/latest/acyclic_sdk/) umbrella crate.
