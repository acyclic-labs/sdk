# acyclic-harness-http

HTTP, SSE, and WebSocket framing for the `acyclic-harness` wire API. Supply a `HarnessWireApi` implementation; this crate does not choose a persistence, authentication, or deployment model for you.

```sh
cargo add acyclic-harness-http
```

See the [adapter API](https://docs.rs/acyclic-harness-http/latest/acyclic_harness_http/), [Harness API](https://docs.rs/acyclic-harness/latest/acyclic_harness/), and [wire protocol](https://github.com/acyclic-labs/sdk/tree/main/proto/harness).
