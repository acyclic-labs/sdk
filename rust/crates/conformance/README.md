# acyclic-conformance

Reusable black-box qualification workloads for public Acyclic provider contracts. Run the relevant suite against your provider implementation before claiming protocol compatibility.

```sh
cargo add acyclic-conformance --dev
```

The crate exposes Filesystem workload vectors and machine-readable reports and qualification receipts. See the [API](https://docs.rs/acyclic-conformance/latest/acyclic_conformance/) and the [protocol directory](https://github.com/acyclic-labs/sdk/tree/main/proto) for the underlying contracts.
