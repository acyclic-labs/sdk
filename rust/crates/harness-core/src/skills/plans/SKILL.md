---
name: plans
description: Keep optional plans, working notes and goal progress in private files.
---
Use ordinary file tools for plans in `volume:///home/plans/` and working notes in
`volume:///home/memory.md`. Markdown task lists work for plans. These files are
private retained storage outside the checkout and are never merged into the repo.
When looping on a goal, `volume:///home/GOAL.md` can record its active, blocked or
done status in frontmatter. Pull these files when they help the task; they need
no per-turn maintenance.
