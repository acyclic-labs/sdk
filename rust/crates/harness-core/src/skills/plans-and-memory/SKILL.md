---
name: plans-and-memory
description: Keep plans and working notes in your home.
---

Plans and notes go in `.volumes/home/plans/` and `.volumes/home/memory.md`, written with the ordinary file tools. Use Markdown task lists for plans and update them as work progresses; keep durable facts, decisions and pointers to evidence in memory.md. Your home is private and retained across turns and resumes, and it is never merged into the project. GOAL.md is used only when looping on a goal (see goal-loop).
