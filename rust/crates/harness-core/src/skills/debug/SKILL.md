---
name: debug
description: Diagnose a reproducible failure and remove its underlying cause.
---
Capture the actual failing input and output. Read the responsible boundary and form a specific hypothesis. Make the smallest discriminating check; preserve the original failure as a negative control when useful. Follow the cause to the shared primitive instead of adding retries, polling or consumer exceptions. Change one cause at a time, verify the original case and explain why the same failure class is now excluded. Keep working notes and commands in private scratch plans or memory when the investigation spans turns.
