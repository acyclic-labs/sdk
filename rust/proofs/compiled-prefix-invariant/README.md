# Original compiled-prefix coordinates

Run `node rust/proofs/qualify.mjs compiled-prefix-invariant`.

The retained mutation turns an inconsistent original label into a successful
absence. The unchanged property must reject it, then two restored collection
properties and the real native grant attenuation property must pass. These
exercise original borrowed keys, physical allocation retirement, per-byte work,
refused read credit and native path grants through the shipping entry points.

Compilation and lookup retain one radix table and the original input vector.
Checked access replaces each panicking bound check with a typed invariant error;
caller work errors remain their original values inside `CompiledPrefixError::Work`.
Lookup adds no allocation, copy, syscall, barrier, round trip, wait or scan.
Its work remains bounded by query bytes, independent of unrelated key count;
arbitrary input width and table compilation are not constant-time operations.
