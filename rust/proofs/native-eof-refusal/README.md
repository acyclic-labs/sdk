# Native retirement after a refused control

```sh
node rust/proofs/qualify.mjs native-eof-refusal
```

The shared qualifier applies the actual retained shutdown inverse, runs the
unchanged real-owner control, restores the exact original source, and requires
the same control to pass. It does not change the oracle or use a timeout.
The original process identity is held across workspace-directory withdrawal;
physical retirement must precede reply-writer release, while the failed control
retains its typed cause and operation identity.

The [native journal control](../../crates/harness/fuzz-native-journal/README.md)
owns the test contract and production mutation. Its shell process fixture uses
the production workspace and native process owners for all three host adapters;
this does not qualify the installed native CLIs or all platforms.
