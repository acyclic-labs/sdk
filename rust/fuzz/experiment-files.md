The experiment_files corpus contains generated declarations for the harness-owned version-1 assignment and version-2 observation formats. They were produced from ordered PowerShell hash tables with ConvertTo-Json -Compress, using population bytes 0 through 31 and replicate zero. The observation seeds exercise unknown values and a known zero cost. The retained target calls the original public decoders, checks canonical re-admission, and rejects surplus input, duplicate versions and a same-arm pair.
